# 人氣充電站

客人在前台下單 → 匯款並回報末五碼 → 你在後台按「已繳費請下單」→ 系統自動挑最划算的上游送單 → 每 15 分鐘同步進度。

```
docs/           前台網站（GitHub Pages 從這個資料夾發布）
  index.html    客人下單頁（含 FAQ）
  admin.html    後台（已繳費請下單、比價表、上游餘額）
  terms.html    服務條款與隱私權政策
  config.js     ← 填 Apps Script 網址
apps-script/
  Code.gs       後端：比價、訂單、自動下單、狀態同步
```

## 設定步驟

1. **建 Google Sheet**：新增一份空白試算表 → 擴充功能 → Apps Script → 把 `Code.gs` 全部貼上並存檔。
2. **初始化**：在 Apps Script 上方選 `setup` → 執行 → 授權。試算表會自動長出 6 個分頁和每小時、每 15 分鐘的排程。
3. **填設定**（「設定」分頁）：`ADMIN_KEY`（後台密碼）、`BANK_INFO`、`LINE_OA_URL`、`ADMIN_EMAIL`、`USD_TWD`。
4. **填上游**（「上游」分頁）：每家一列，填 API 網址、API 金鑰、幣別（USD / TWD），`啟用` 設為 TRUE。
5. **抓價格**：在 Apps Script 執行 `refreshPrices`，「上游服務」分頁會列出每家的所有服務。
6. **建對應**（「對應」分頁）：每列填 `商品ID`、`上游`、`服務ID`。同一個商品可以對應多家，系統會自動比價。
   - `加權`：實測掉量多的服務填 0.1～0.3，比價時會被視為比較貴。
   - 沒有補單的服務，會自動套用 `NO_REFILL_PENALTY` 懲罰。
7. **部署**：部署 → 新增部署作業 → 類型選「網頁應用程式」→ 執行身分選「我」、存取權選「所有人」→ 複製網址貼到 `docs/config.js`。
8. **發布前台**：GitHub repo → Settings → Pages → Branch: `main`、資料夾選 `/docs`。

> 之後改了 Code.gs，要用「管理部署作業 → 編輯 → 新版本」更新，網址才不會變。

## 售價怎麼算

售價（每千）＝「商品」表的「售價每千」；但利潤低於 MIN_MARGIN（預設 30%）時會自動調高。沒填售價時改用 成本 × (1 + MARKUP)。

比價分數 ＝ 成本 × (1 + 加權 + 無補單懲罰)，分數最低的優先下單；如果失敗，會自動改用下一家。

## 會員與優惠碼

- **會員**：客人下單時填手機號碼就是會員，不用註冊或設密碼。同一支手機之前有成功付款的訂單，之後自動打「設定」表的 `MEMBER_DISCOUNT`（0.05 = 95 折，0 = 關閉）。
- **優惠碼**：在「優惠碼」工作表新增一列：代碼、折扣（0.1 = 9 折）、啟用（TRUE/FALSE）、到期日（可留空）、可用次數（可留空 = 不限）。逾期或取消的訂單不算用掉次數。
- 老客折扣和優惠碼不疊加，系統自動選比較划算的那個；折完不會低於上游成本的 1.1 倍。

## 自動對帳（手機轉發入帳通知）

用 Android 的 MacroDroid 把「將來銀行」的入帳推播轉給後台：

- 觸發：通知 → 收到通知 → App 選「將來銀行」→ 內容包含「存入」
- 動作：HTTP 請求（POST）
  - 網址：`<Web App 網址>?action=bankNotify&secret=<設定表的 NOTIFY_SECRET>`
  - 內容類型：`text/plain`，內文：`[notification]`

後台會從「NT$ X 存入」讀出金額，對到付款期限內唯一一筆同金額訂單就自動標成已付款並下單。每則通知都記在「入帳紀錄」工作表。

## 卡單、備援與退款

- 上游下單後超過 `STUCK_HOURS`（預設 6）小時一個都沒送，系統自動向上游申請取消並寄信通知你。
- 上游取消（不論是卡單取消或上游自己取消）時，系統自動改用「對應」表裡下一個還沒試過的服務重新下單；全部試過都不行才標成需退款。
- 需退款（全額或部分完成的差額）時，客人在網站「查詢訂單」輸入訂單編號，驗證手機或姓名後填退款帳戶；你會收到通知信，轉帳後在後台按「標記已退款」。
